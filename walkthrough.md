# Walkthrough

## Изменения
- Разработана архитектура управления заказами, корзиной и складом в соответствии с правилами Stage 9.
- Создана миграция базы данных `20260919173000_stage9_orders_search.sql` со следующими возможностями:
  - Создание таблиц `orders`, `order_items`, `cart_items`, `search_synonyms`.
  - Внедрение enum типов `order_status`.
  - Установка строгих RLS политик на таблицы корзины и заказов.
  - Реализация атомарной RPC-функции `complete_order` в PostgreSQL для управления остатками (Inventory) и изменения статусов (SINGLE/SOLD, INVENTORY/OUT_OF_STOCK) с использованием Row-Level Locks (`FOR UPDATE`) для защиты от race conditions.
  - Подключение `pg_trgm` GIN индексов на `title` и `description` для оптимизации Smart Search.
- Реализованы Server Actions:
  - `src/app/actions/cart.ts` (Управление корзиной и группировка товаров по `seller_id` при checkout)
  - `src/app/actions/orders.ts` (State machine переходов статуса и вызов `complete_order` RPC)
  - `src/app/actions/settings.ts` (Сохранение профиля)
- Созданы новые страницы:
  - `/cart`: Просмотр товаров в корзине, изменение количества для INVENTORY с лимитом по остатку, и оформление заказов (Checkout)
  - `/orders`: Страница покупателя с историей покупок (Мои покупки)
  - `/orders/[id]`: Подробная информация для покупателя, включая действия (Отменить заказ)
  - `/seller/orders`: Страница продавца с новыми заявками от клиентов
  - `/seller/orders/[id]`: Управление заявкой (Подтвердить, Отклонить, Завершить сделку, Отменить)
  - `/settings`: Форма редактирования профиля (Имя, Регион) с использованием `REGIONS` из `src/lib/regions.ts`
- Обновлен `ProductPage` (`/product/[id]`):
  - Добавлены кнопки "Купить сейчас" и "В корзину" с помощью клиентского компонента `BuyButtons`.
  - Применен селектор количества для товаров типа `INVENTORY`.
  - Кнопки неактивны, если `status !== ACTIVE`.
  - Кнопки не отображаются, если пользователь — продавец этого товара.
- Улучшен поиск (Smart Search):
  - Модифицирован `src/app/(main)/catalog/page.tsx` для поддержки умного поиска по `search_synonyms`.
  - Поиск работает быстро через `.or` используя GIN индексы и не ломает существующий `PriceFilter` и другие параметры фильтрации.
- Добавлены ссылки на новые страницы в `UserMenu` (`header-auth.tsx`) и `Header` (`header.tsx`).

## Результаты проверок (Verification)
- [x] Атомарное снижение количества товаров (Atomic Inventory decrement) строго реализовано на уровне СУБД (RPC), что предотвращает гонки при параллельном завершении (Race Condition) и дабл-клик (Idempotency).
- [x] Невозможно добавить в корзину больше, чем есть на складе.
- [x] Пользователь не может купить собственный товар.
- [x] Группировка заказов по продавцу работает на уровне Checkout (одна корзина -> несколько заказов разным продавцам).
- [x] Поиск поддерживает синонимы, извлекая их из БД.
- [x] Команды `npm run build` и `npx supabase db push` успешно выполнены. Ошибок типов нет.
