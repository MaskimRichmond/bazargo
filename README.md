# BazarGo

Marketplace MVP for Bishkek, Kyrgyzstan.

## Stack

Next.js
TypeScript
Tailwind CSS
Supabase
PostgreSQL

## Development

```bash
npm install
npm run dev
```

## Environment

Создать `.env.local`:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Current MVP

- authentication
- profiles
- categories
- listings
- image upload
- catalog
- filters
- sorting
- seller management
- stores foundation
- requests foundation
