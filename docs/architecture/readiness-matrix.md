# BazarGo Readiness Matrix

## C2C — частные продавцы и покупатели
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Регистрация, авторизация, профиль | DONE_VERIFIED | Supabase OTP, Server Actions |
| Создание, редактирование, удаление объявлений | IMPLEMENTED_UNVERIFIED | UI, `publishListing`, транзакционное хранилище. Нужен E2E. |
| Загрузка, валидация, удаление фотографий | DONE_VERIFIED | `validateImage` на сервере, безопасное удаление RPC. |
| Каталог, категории, поиск, пагинация | IMPLEMENTED_UNVERIFIED | Поиск по `search_catalog_listings`, фильтры `in`. |
| Избранное, чат, уведомления | IMPLEMENTED_UNVERIFIED | Realtime чаты с удалением каналов, защита от утечек. |
| Заказы, статусы, отмена | IMPLEMENTED_UNVERIFIED | Корзина, валидация остатков (qty > stock), переход статусов. |
| Отзывы после сделки | MISSING | Таблицы и функциональность отзывов отсутствуют в БД и UI. |

## B2C — магазины и компании
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Регистрация и модерация магазина | IMPLEMENTED_UNVERIFIED | `stores` table (PENDING, APPROVED), модерация админкой. |
| Витрина, каталог, товары, отзывы | DONE_VERIFIED | У магазинов есть публичная витрина `/store/[slug]` с каталогом, отзывами, рейтингом и ответами продавца. |
| Управление объявлениями магазина | IMPLEMENTED_UNVERIFIED | `seller/orders` и `my-store`. |
| Работа с покупателями | IMPLEMENTED_UNVERIFIED | Через стандартный `messages` (чат). |
| Рейтинг и жалобы на магазин | PARTIAL | Жалобы (reports) работают. Рейтинги и отзывы - MISSING. |
| Инструменты ассортимента/аналитики | MISSING | Графиков и массового импорта нет. |

## B2B — бизнес и оптовые сделки
| Функция | Статус | Комментарий |
|---------|--------|-------------|
| Бизнес-профили и сведения | IMPLEMENTED_UNVERIFIED | `b2b_applications` реализованы для запросов на статус. |

| Запросы на закупку (Requests) | DONE_VERIFIED | Реализовано в `b2b_offers` (через модалку в товаре) и UI карточек в чате. |
